# 36104 Session 2 artefacts

This repository contains three Streamlit deployment entry points for Session 2:

- `part_c_uber/app.py` — Streamlit 1: an interactive Uber pickups explorer.
- `part_d_stars/app.py` — Stars: the course-provided star app.
- `part_e_multipage/app.py` — Streamlit 2: a multipage data app; its pages live in `part_e_multipage/pages/`.

Deploy each entry point separately with Streamlit Community Cloud. The resulting three URLs are the files requested for Parts C, D and E respectively.

Parts A and B are image artefacts and are prepared separately from the Streamlit deployments.
